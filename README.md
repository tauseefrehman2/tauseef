# Tauseef GitHub Pages Portfolio

A handcrafted single-page portfolio for a Flutter developer, built for GitHub Pages.

## Files

- `index.html` contains the page structure and content.
- `styles.css` contains the complete visual system and responsive layout.
- `script.js` adds reveal animations on scroll.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. Open repository `Settings`.
3. Go to `Pages`.
4. Set source to `Deploy from a branch`.
5. Select the `main` branch and `/root`.
6. Save and wait for GitHub Pages to publish.

## Customize

- Replace the email address in `index.html`.
- Replace GitHub and LinkedIn links in `index.html`.
- Update project descriptions with your real work.
